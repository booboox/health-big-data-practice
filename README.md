## 资料对应与范围

- 作业按用户指定的 session 标题归档。工作单和原包内部可能使用另一套讲次编号，以主题对应，不改动原件编号。
- `session4-统计检验` 中新增了正确的 `hypothesis.zip` 资料。原先的 `student-package` 实为高维数据与降维材料，保持原样供追溯；该课独立 PPT 仍待补充。
- 统计检验的两个 Word 文件内容完全相同，首页只链接主文件，备用原件保留在课程目录。
- 七份作业均有用户提供的 Word 文件；这表示材料已归档，不等于对作答完整性或正确性的额外认证。
- AI 对话目前覆盖线性模型、SVM、集成学习；其他课尚未取得真实记录。对话不是实验结果的替代证据。
- 网页预览忠于原工作单文字，但自动编号、合并单元格及公式排版可能不同。原件为最终核对依据。
- 本次主要整理导航和材料，本次未完整重跑原实验。已有数据来源与许可说明保留在各课原资料中。
