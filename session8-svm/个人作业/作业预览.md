### 中英术语对照（工作含义）

| 术语 | 本册中的工作含义 |
| --- | --- |
| 分类超平面（hyperplane） | 满足 f(x)=wᵀx+b=0 的点；二维时是一条直线，六个变量时是六维空间中的一个五维“平面”。 |
| 决策得分（decision score） | f(x) 的数值；正负号给出类别，数值本身不是患病概率。 |
| 几何距离 | 样本到超平面的垂直距离 \|f(x)\|/‖w‖。 |
| 间隔（margin） | 硬间隔时指分类边界到最近训练样本的距离；软间隔 SVM 中指两条虚线 f=±1 围成的带，允许样本进入带内。线性 SVM 中这条带的宽度为 2/‖w‖（本册称“带宽”）。 |
| 支持向量（support vector） | 落在间隔线上、间隔内或被判错的训练样本；训练后的边界只由它们决定。 |
| 软间隔（soft margin） | 允许部分样本进入间隔甚至被判错的 SVM。 |
| 合页损失（hinge loss） | max(0, 1−y·f(x))，用来计量一个样本的违例程度。 |
| C | scikit-learn 中违例的惩罚权重（与 ISLR 教材中的“预算 C”方向相反）。 |
| 核函数（kernel） | 直接算出映射后两个样本内积的函数 K(x,z)。 |
| gamma | RBF 核中控制相似度随距离衰减快慢的参数；在多项式核中是内积前的缩放系数（本册固定）。 |
| 标准化（standardization） | 每个变量减去训练集均值、除以训练集标准差。 |
| 召回率与平衡准确率 | 召回率：某类记录中被判对的比例；平衡准确率：两类召回率的平均。 |

### 启动概念读页

一个样本是一组测量值。二维时把它写成 x=(u,v)，线性得分 f(x)=w₁u+w₂v+b：w₁、w₂ 是两个坐标的权重，b 平移直线。f(x)=0 的点构成分类边界；f>0 判为一类，f<0 判为另一类。六个测量时 f(x)=w₁x₁+…+w₆x₆+b，f(x)=0 是六维空间中的一个“超平面”，二维时它就是一条直线。向量长度 ‖w‖=√(w₁²+w₂²)。

间隔（margin）原意是边界离最近训练样本有多远（硬间隔）。图 S1 中实线是 f=0，两条虚线是 f=+1 和 f=−1；对线性 SVM，得分已按 SVM 的约定定好尺度，两条虚线之间的垂直宽度是 2/‖w‖（本册称“带宽”）。软间隔 SVM 允许一些样本进入虚线之间，甚至落到错误一侧，这时“间隔”指这条虚线带，而不是到最近样本的距离；C 是这种“违例”的惩罚权重。RBF 核能画出弯曲边界，gamma 控制它的相似度随距离衰减的快慢。课堂上先记录现象，课外再用证据解释原因。

### Q1 两条候选线的抗扰动差异

对应目标：LO1、LO2    证据：表 A1、表 A2    约16分钟    完成后更新：总答案追踪表“T1 几何依据”行

学习重点：加权和决定边界所在的位置，但要比较“离边界多远”，必须把得分除以 ‖w‖ 变成几何距离。阅读：定向阅读指南 R1；scikit-learn 指南 1.4.7 开头的线性可分示意图（https://scikit-learn.org/stable/modules/svm.html#mathematical-formulation）。

距离读页：记超平面 H 为 f(x)=0 的点。点 x 到 H 的垂直距离为下式；对带标签的样本，y·f(x)/‖w‖ 是带符号的间隔，为负表示判错。把 w 和 b 同时乘一个正数，分类线不变，原始得分却会变。对一条固定的线性边界，若一个点受到的扰动（位移向量）长度小于它到边界的距离，这个点就不会越过边界；这一保障只针对已有的点，不保证未来样本也离边界足够远。

$d(x,H)=|wᵀx+b|/‖w‖$

在线性可分的硬间隔 SVM 中，可以把得分尺度约定为所有训练点满足 yᵢf(xᵢ)≥1、最近的点取等号。此时每侧的最小距离为 1/‖w‖，最小化 ½‖w‖² 就等价于最大化间隔。较大的间隔让已有的点能容忍更大的扰动，也限制了可选边界的范围；这是它可能有助于泛化的理由，但不是新样本准确率的保证——训练样本是否有代表性、特征尺度和噪声同样影响泛化。

Q1 距离计算：为比较候选线 a 与 b 离样本有多远，用表 A2 的六个样本逐行计算：最近样本（可能不止一个）、最小 |f|、‖w‖ 与最小几何距离（=最小 |f|/‖w‖）。第三行把线 a 的得分改写成 f=5u，检验同一条几何边界的最小距离是否改变。

### Q3 C 控制的究竟是哪一种代价

对应目标：LO4    证据：图 S1、表 B2、图 B1    约15分钟    完成后更新：总答案追踪表“T3 容错权衡”行

学习重点：软间隔（soft margin）允许间隔违例。本节标签 yᵢ 取−1 或+1（模拟图中的“类0”在公式里编码为−1，“类1”为+1）。令 mᵢ=yᵢf(xᵢ)，合页损失（hinge loss）为 max(0,1−mᵢ)：mᵢ≥1 时无损失；0<mᵢ<1 时已判对，但落在间隔内，仍有损失；mᵢ<0 才是判错。凡 mᵢ<1 的样本都算间隔违例（包括判错的样本）。样本的最低松弛量 ξᵢ 等于这个损失。

$最小化 J = ½‖w‖² + C·Σᵢ max(0, 1−yᵢf(xᵢ))$

读目标函数时只需分辨两项：第一项偏好小的 ‖w‖（即宽的带宽 2/‖w‖），第二项累计违例。在特征表示、样本和核都固定时，C 越大，违例越“贵”，模型越倾向于减少违例、接受更窄的带宽；这不等于每个分类指标都会随 C 单调变好。软间隔的虚线带里可以有样本，所以它未必是“完全空白”的区域。阅读：定向阅读指南 R2（注意 ISLR 中 C 的方向相反）与 R3（https://scikit-learn.org/stable/modules/svm.html#svc）。

### Q4 三种核怎样表示相似性

对应目标：LO5    证据：图 C1、表 C1    约20分钟    完成后更新：总答案追踪表“T4 核的理由”行

核读页：内积 xᵀz 是对应坐标乘积之和。若先把输入映射成新坐标 φ(x)，就可以在新坐标中使用线性边界；核技巧（kernel trick）用 K(x,z)=φ(x)ᵀφ(z) 直接算出这个内积，不必逐项构造全部新坐标。核必须是某个映射下的内积，并非任意相似度都能直接作为 SVM 的核。

$线性 K(x,z)=xᵀz$

$多项式 K(x,z)=(gamma·xᵀz+r)ᵈ$

$RBF K(x,z)=exp(−gamma·‖x−z‖²)$

多项式核的次数 d 控制可表达的交互阶数，r 是常数项。RBF 的 gamma 越大，相似度随距离衰减越快，每个训练样本的影响范围越小。核 SVM 仍然是在隐式的新坐标中找一个超平面，映射回原始坐标时可以呈现为曲线。训练后的预测只用到支持向量：

$f(x)=Σ αᵢyᵢK(xᵢ,x)+b$

式中求和只对支持向量集合 SV 中的样本 i 进行，αᵢ 是训练求得的系数；这里只解释预测的结构，不要求推导对偶优化。核 SVM 图中的 f=±1 是得分等高线，不能按原始平面上的间距与线性带宽比较。阅读：定向阅读指南 R4（https://scikit-learn.org/stable/modules/svm.html#kernel-functions）。
