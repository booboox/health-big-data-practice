## 来源与运行

课程代码来源于用户提供的资料包；个人实验代码另在 `homework/` 中标识。新增 `.py` 是原实验的查阅/运行入口，不表示新完成了个人作业。

在本课目录安装依赖：`python -m pip install -r requirements.txt`。

在本课目录执行：`python code/lesson.py`。Notebook 提取版会切换到原 Notebook 所在目录，以兼容原相对路径；交互展示建议使用原 Notebook。原课程依赖、数据约束和版本要求仍然适用。
